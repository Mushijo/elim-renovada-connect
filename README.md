# Elim Renovada Connect

Crie um site institucional completo para a Igreja Batista Renovada Elim.

Objetivo

O site deve transmitir uma identidade cristã moderna, acolhedora e inspiradora, incentivando visitantes a conhecerem a igreja e participarem dos cultos e eventos.

O design precisa passar sensação de:

 Excelência

 Reverência

 Modernidade

 Esperança

 Organização

Evite aparência de sites antigos de igrejas.

Utilize como referência a identidade visual da Igreja Batista Renovada Elim.

Considere que existe um logotipo oficial (fornecido pelo usuário) que deve ser preservado sem alterações.

Estilo visual desejado

O resultado deve parecer um site profissional desenvolvido por uma agência especializada em igrejas, com acabamento de alto nível, foco em experiência do usuário (UX), excelente responsividade e ótima performance. O layout deve ser limpo, sofisticado e transmitir acolhimento, evitando elementos excessivamente chamativos.

Importante: utilize imagens reais e autênticas da Igreja Batista Renovada Elim sempre que forem fornecidas pelo usuário. Não recrie nem altere o logotipo oficial. Estruture o projeto para que todas as imagens e textos possam ser facilmente substituídos posteriormente por meio de um CMS ou painel administrativo. Além disso, prepare a arquitetura para futura integração com transmissões ao vivo, calendário de eventos e gestão de conteúdo.
